## Общий план задач

### 1. Работа с датасетом
- Подсчёт агрегатов: 
  - Вычислить c_sum и другие агрегаты по ИНН.
  - Дискретизировать значения (например, по квантилям).
- Добавление новых фичей:
  - Активность пользователей (индикаторы, частота взаимодействий).
  - Фичи из сообщений
- Negative sampling:
  - Определить логику создания негативных примеров.
  - Реализовать в рамках партиций или динамически добавлять в батчи.
- Обработка большого объёма данных:
  - Хранение данных в партициях, чтение через Spark.
  - Создание пайплайна обработки с сохранением результата в Hadoop.
- Инициализация через Hydra:
  - Реализовать конфигурацию датасета (пути к данным, параметры обработки).

### 2. Модель
- Корректировка модели:
  - Поддержка входных данных с обработанными фичами.
  - Подключение эмбеддингов и обработка тензоров (PyTorch).
- Инициализация через Hydra:
  - Добавить параметры модели и эмбеддингов в конфиги.
- Предобученные эмбеддинги:
  - Реализовать загрузку предобученных эмбеддингов, если это необходимо.

### 3. Трейнер
- Итерация по партициям:
  - Создание DataLoader или аналога для партиционированных данных.
  - Реализация логики для обучения и добавления негативных примеров.
- Трекинг метрик:
  - Подсчёт и логирование метрик во время обучения.
- Evaluation:
  - Реализовать оценку модели, возможно, с векторной базой для теста.

### 4. Лосс
- Реализация Warp Loss:
  - Найти формулу и реализовать в PyTorch.
- Кросс-энтропия:
  - Использовать как базовый лосс, если Warp Loss сложно внедрить.

### 5. Метрики
- MAP@k:
  - Реализовать подсчёт метрики для валидации и теста.
- Другие метрики:
  - Добавить Precision@k, Recall@k, если нужно.

### 6. Логирование
- Wandb:
  - Настроить логирование лосса, метрик, гиперпараметров.
- TensorBoard:
  - Исследовать и настроить, если требуется.

### 7. Конфиги для экспериментов
- Создать общую структуру конфигов для датасета, модели, обучения.
- Настроить автоматическое управление параметрами через Hydra.

### 8. Запуск на ML Space
- Обезличивание данных:
  - Убедиться, что данные можно использовать после label encoding.
- Обучение на GPU:
  - Настроить логику загрузки данных и выполнения обучения.
- Сохранение и дообучение:
  - Реализовать пайплайн сохранения модели и её дообучения.
